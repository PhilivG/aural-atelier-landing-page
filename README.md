# Aural Atelier

Landing page conceptual de moda creada como pieza de portafolio.

## Vista previa

https://philivg.github.io/aural-atelier-landing-page/

## Descripcion

Aural Atelier es una propuesta con direccion fashion campaign, tono aspiracional y una estetica editorial contemporanea. La landing esta pensada para presentar una coleccion, un drop o un lanzamiento de marca con identidad visual fuerte.

## Archivos

- `index.html`
- `styles.css`
- `script.js`

## Incluye

- hero con narrativa de campana
- scroll suave entre secciones
- navegacion con seccion activa
- animaciones de entrada al hacer scroll
- microinteracciones sutiles
- diseno responsive

## Secciones principales

- drop
- coleccion
- capsule 05
- manifiesto
- cierre de lanzamiento

## Tecnologias

- HTML5
- CSS3
- JavaScript vanilla

## Publicacion en GitHub Pages

Sube estos archivos a un repositorio independiente:

- `index.html`
- `styles.css`
- `script.js`

Luego activa GitHub Pages desde la rama principal.

## Nota

Este proyecto fue creado como concepto visual de portafolio y puede adaptarse facilmente a una marca real.
